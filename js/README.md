# Parking Management System

A simple Parking Management System built using HTML, CSS, and JavaScript.

## Features

- Create parking slots
- Park different types of vehicles
- Bike requires 1 slot
- Car requires 3 slots
- Truck requires 5 slots
- Shows available and occupied slots
- Shows parked vehicles in a table
- Remove parked vehicles
- Updates parking slots after parking or removing a vehicle
- Prevents the same vehicle from being parked twice

## Vehicle Types

| Vehicle | Required Slots |
|---------|----------------|
| Bike    | 1              |
| Car     | 3              |
| Truck   | 5              |

## Technologies Used

- HTML
- CSS
- JavaScript
